# RFC-0023 — Remote Node Protocol

**Status:** Draft

**Version:** 0.1

Depends on:

- RFC-0018 Distributed Runtime
- RFC-0020 Security Model

---

# Цель

Определить единый протокол взаимодействия
между удаленными узлами ICG.

Любой Worker,
независимо от языка,
операционной системы
или реализации,
должен использовать одинаковый протокол.

---

# Главная идея

ICG общается
не с процессами,
не с API,
а с Node.

Node —

стандартизированная вычислительная единица.

---

# Архитектура

```
Runtime

↓

Protocol

↓

Node

↓

Executor
```

---

# Node

Node обязан поддерживать
следующие операции

```
Register

Heartbeat

Capabilities

Execute

Cancel

Artifact Upload

Shutdown
```

---

# Protocol

MVP использует

```
HTTP + JSON
```

Позже могут появиться

```
gRPC

QUIC

WebSocket

libp2p
```

Без изменения Runtime.

---

# Registration

Node отправляет

```json
{
  "id": "...",
  "version": "...",
  "capabilities": [...],
  "resources": [...]
}
```

Runtime отвечает

```
Registered
```

или

```
Rejected
```

---

# Heartbeat

Node периодически сообщает

```
CPU

RAM

Load

Running Tasks

Health
```

Runtime обновляет
Resource Graph.

---

# Execute

Runtime отправляет

```
Execution Node

↓

Contract

↓

Artifacts

↓

Configuration
```

Node возвращает

```
Result

Artifacts

Metrics
```

---

# Streaming

Protocol поддерживает

```
stdout

stderr

logs

partial artifacts

token streams
```

Execution может наблюдаться
в реальном времени.

---

# Cancellation

Runtime может отправить

```
Cancel(TaskID)
```

Node обязан
попытаться остановить выполнение.

---

# Timeouts

Каждое сообщение
имеет Timeout.

Истекший Timeout
считается ошибкой связи.

---

# Compression

Protocol может использовать

```
gzip

zstd
```

для передачи
больших Artifact.

---

# Compatibility

Каждый Node объявляет

```
protocol_version
```

Runtime поддерживает
несколько поколений протокола.

---

# Authentication

Protocol не определяет
способ аутентификации.

Он использует
Security Layer.

---

# Future

Позже Protocol сможет поддерживать

```
P2P Discovery

NAT Traversal

Encrypted Channels

Mesh Networks

Broadcast Tasks
```

---

# Acceptance Criteria

✓ существует Protocol;

✓ Node может зарегистрироваться;

✓ Runtime может отправить Execution;

✓ Node возвращает Result;

✓ поддерживается Heartbeat;

✓ поддерживается Streaming;

✓ Runtime совместим с несколькими версиями Protocol.
