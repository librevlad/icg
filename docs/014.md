# RFC-0014 — Provider Manifest

**Status:** Draft

**Version:** 0.1

Depends on:

- RFC-0012 Provider SDK
- RFC-0013 Capability Schema

---

# Цель

Определить декларативное описание Provider.

Provider должен подключаться
без написания специального кода.

Manifest является единственным
описанием Provider.

---

# Главная идея

ICG не должен знать,
что такое Gemini,
Claude,
Groq
или Oracle.

Он читает только Manifest.

---

# Архитектура

```
provider.yaml

↓

Discovery

↓

Capability Graph
```

---

# Manifest

Минимальная структура

```yaml
id:

name:

version:

author:

license:

homepage:

description:
```

---

# Capabilities

Manifest обязан содержать

```yaml
capabilities:

- coding

- reasoning

- verification
```

---

# Executors

Для каждой Capability
может быть указан Executor.

```yaml
executors:

coding:

class: GeminiExecutor

reasoning:

class: GeminiExecutor
```

---

# Platform

Manifest может ограничивать
поддерживаемые платформы.

Например

```yaml
platform:

linux

windows

darwin

arm64

amd64
```

---

# Cost

Manifest описывает стоимость.

Например

```yaml
cost:

free
```

или

```yaml
cost:

subscription
```

или

```yaml
cost:

per_token
```

---

# Requirements

Manifest может объявлять
зависимости.

Например

```yaml
requires:

binary:

- gemini

environment:

- GEMINI_API_KEY
```

---

# Healthcheck

Manifest определяет
команду проверки.

```yaml
healthcheck:

command:

gemini --version
```

---

# Benchmark

Manifest содержит
список Benchmark.

```yaml
benchmark:

coding

json

reasoning
```

---

# Configuration

Manifest определяет
доступные параметры.

```yaml
config:

timeout

temperature

max_tokens
```

---

# Security

Manifest обязан объявлять

необходимые разрешения.

Например

```yaml
permissions:

filesystem

network

docker
```

Policy может учитывать
эти разрешения.

---

# Discovery

Discovery не знает Provider.

Он читает Manifest.

Если Manifest валиден —

Provider может быть зарегистрирован.

---

# Version Compatibility

Manifest обязан указывать

совместимую версию SDK.

Например

```yaml
sdk:

1.x
```

---

# Future Extensions

Позже Manifest сможет содержать

```yaml
streaming

pricing

rate_limits

telemetry

resource_usage

supported_models
```

Без изменения существующих полей.

---

# Пример

```yaml
id: gemini-cli

name: Gemini CLI

version: 1.2.0

sdk: 1.x

capabilities:

- reasoning

- coding

- review

requires:

binary:

- gemini

environment:

- GEMINI_API_KEY

permissions:

- filesystem

- network

cost:

free
```

---

# Acceptance Criteria

✓ каждый Provider имеет Manifest;

✓ Discovery работает только через Manifest;

✓ Manifest описывает Capability;

✓ Manifest описывает зависимости;

✓ Manifest описывает требования окружения;

✓ новый Provider подключается без изменения кода Engine.
