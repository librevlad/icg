# RFC-0022 — Plugin System

**Status:** Draft

**Version:** 0.1

Depends on:

- RFC-0012 Provider SDK
- RFC-0014 Provider Manifest
- RFC-0021 Benchmark Suite

---

# Цель

Определить механизм расширения ICG.

Любая функциональность,
не являющаяся частью ядра,
должна подключаться
как Plugin.

---

# Главная идея

Ядро ICG
должно оставаться минимальным.

Все остальное —

Plugin.

---

# Plugin Types

MVP поддерживает

```
Provider

Capability

Benchmark

Policy

Planner

Discovery Source

Storage Backend
```

---

# Plugin Interface

Минимальный интерфейс

```python
Plugin

id

version

manifest()

initialize()

shutdown()
```

---

# Plugin Manifest

Каждый Plugin
имеет Manifest.

```yaml
id:

name:

version:

type:

sdk:

dependencies:
```

---

# Plugin Lifecycle

```
Install

↓

Validate

↓

Initialize

↓

Register

↓

Active

↓

Shutdown

↓

Remove
```

---

# Registration

Plugin
не регистрирует себя самостоятельно.

Plugin Manager
обнаруживает Manifest
и выполняет регистрацию.

---

# Isolation

Plugin

не может

изменять ядро.

Он взаимодействует
только через публичные интерфейсы.

---

# Dependencies

Plugin
может зависеть
от других Plugin.

Например

```yaml
depends:

provider-sdk

benchmark-suite
```

---

# Compatibility

Plugin обязан объявить

совместимую версию SDK.

Например

```yaml
sdk:

1.x
```

---

# Events

Plugin
может подписываться
на Event Bus.

Например

```
ContractCompleted

↓

Plugin
```

или

```
ProviderDiscovered

↓

Plugin
```

---

# Discovery

Discovery способен
обнаруживать Plugin.

После проверки
Plugin становится доступным системе.

---

# Security

Plugin работает
в рамках Security Layer.

Он получает

только разрешенные Capability
и Resource.

---

# Repository

В будущем

Plugin могут
распространяться
через Registry.

Например

```
plugin install

gemini-cli
```

или

```
plugin install

oracle-worker
```

---

# Future

Plugin System
должен поддерживать

```
Hot Reload

Remote Plugins

Signed Plugins

Sandboxed Plugins

Marketplace
```

Без изменения API.

---

# Acceptance Criteria

✓ существует Plugin Interface;

✓ Plugin имеет Manifest;

✓ Plugin проходит регистрацию;

✓ Plugin может быть удален без изменения ядра;

✓ Plugin использует Event Bus;

✓ Plugin System расширяем;

✓ ядро не зависит от конкретных Plugin.
