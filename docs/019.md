# RFC-0019 — Artifact Store

**Status:** Draft

**Version:** 0.1

Depends on:

- RFC-0002 Contract
- RFC-0008 Memory
- RFC-0018 Distributed Runtime

---

# Цель

Определить единое хранилище
всех результатов выполнения ICG.

Execution производит не только ответы.

Он производит артефакты.

---

# Главная идея

Все результаты работы системы —
артефакты.

Например

```
Patch

Log

Report

Binary

Screenshot

Coverage

Trace

JSON

Markdown
```

Они должны храниться одинаково.

---

# Архитектура

```
Execution

↓

Artifact

↓

Artifact Store

↓

Memory
```

---

# Artifact

Минимальная модель

```python
Artifact

id

type

owner

contract

producer

created_at

metadata

location
```

---

# Типы

MVP

```
text

json

patch

file

directory

log

report

binary
```

---

# Producer

Каждый Artifact знает

кто его создал.

Например

```
Gemini

Pytest

Docker

Local Bash

Oracle VM
```

---

# Ownership

Artifact принадлежит

Contract.

Все артефакты
одного выполнения
могут быть восстановлены.

---

# Storage

Artifact Store
не определяет

где хранить данные.

Это может быть

```
Filesystem

SQLite

S3

Object Storage

Git
```

---

# Addressing

Каждый Artifact
имеет постоянный URI.

Например

```
artifact://logs/123

artifact://patch/18

artifact://report/5
```

Компоненты никогда
не используют
абсолютные пути.

---

# Immutability

Artifact
после создания

не изменяется.

Изменение —

новый Artifact.

Это обеспечивает
полную историю.

---

# Relationships

Artifact
может зависеть
от других Artifact.

Например

```
Patch

↓

Test Report

↓

Coverage
```

Получается Artifact Graph.

---

# Garbage Collection

Store может удалять

временные Artifact.

Политика хранения

не входит
в этот RFC.

---

# Streaming

Некоторые Artifact
могут создаваться постепенно.

Например

```
Logs

Console Output

Streaming Tokens
```

Store должен поддерживать
дозапись.

---

# Remote Storage

Artifact Store
может использовать

```
Oracle Object Storage

S3

MinIO

Git LFS
```

без изменения API.

---

# Acceptance Criteria

✓ существует Artifact Model;

✓ каждый Artifact имеет URI;

✓ Artifact неизменяем;

✓ все результаты Execution становятся Artifact;

✓ Store не зависит от конкретного способа хранения;

✓ Artifact можно восстановить по Contract.
